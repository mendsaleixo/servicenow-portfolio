## Questões

### Q1 — Criar registro baseado em task a partir do Catalog

Which allows the creation of a task-based record from Service Catalog?

- [ ] Record Producers
- [ ] UI Builder
- [ ] Assignment Rule
- [ ] UI Actions
- [ ] Flow Designer

<details>
<summary>💡 Ver resposta e explicação</summary>

✅ **Record Producers** — permitem criar registros baseados em task diretamente a partir de um formulário do Service Catalog.
❌ UI Builder — cria/customiza interfaces, não gera registros a partir do catálogo.
❌ Assignment Rule — atribui registros automaticamente, não os cria a partir do catálogo.
❌ UI Actions — adiciona botões/ações a formulários e listas, não cria registros via catálogo.
❌ Flow Designer — automatiza processos, mas não é o mecanismo de criação do registro a partir do Catalog.

</details>

### Q2 — Scripts que rodam no navegador

Which type of scripts run in the browser?

- [ ] UI Policies
- [ ] Script Includes Scripts
- [ ] Access Control Scripts
- [ ] Business Rule Scripts

<details>
<summary>💡 Ver resposta e explicação</summary>

✅ **UI Policies** — são regras client-side, executadas no navegador, para controlar comportamento de campos.
❌ Script Includes Scripts — rodam no servidor, chamados via GlideAjax ou outros scripts server-side.
❌ Access Control Scripts — scripts de ACL rodam no servidor para controlar acesso a dados.
❌ Business Rule Scripts — Business Rules rodam no servidor, disparadas por eventos de banco de dados.

> Conexão com o bloco: a mesma lógica client-side x server-side é o que separa **Catalog UI Policy** de **UI Policy comum** — ambas rodam no navegador.

</details>
